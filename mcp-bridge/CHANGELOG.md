## [2.3.8] - 2026-10-05

- 新增 `footprint_save`：当前独立封装完整源码快照（读取时状态）通过一次 `getDocumentSource` 和一次 `lib_Footprint.updateDocumentSource` 原样写回同库同文档；默认 30 秒、可选 5–120 秒预算。保存另核对身份，不额外读取七类图元，不自动关闭页面或重建器件。
- 写入前最后一次身份读取后核对连接、活动角色和租约；返回真实身份、`scope:"library_source"`、`sharedSource:true`、`sourceLength` 和库保存 ACK。共享源更新可能影响所有引用实例，不提供仅此实例的封装重绑定。
- 显式 false 为明确未获 ACK，返回 `saved:false`、`nativeCallSettled:true`，不证明源码未改变；undefined 是已结束但效果未知，返回 `commitUnknown:true`、`readbackRequired:true`、`nativeCallSettled:true`，不带 `saved` 或 `saveAcknowledged`，不强制宿主重启，须同库同文档完整回读恢复；RPC 未确认或超时保留未知提交并要求同库同文档完整 `footprint_read` 恢复。ACK 后身份失败保留 `saved:true`、`saveAcknowledged:true`，同时返回 `ok:false`、`identityVerified:false`，不把已知 ACK 改成未知保存。编辑状态回读不代替保存或引用 PCB 持久性证明。
- EDA 3.2.181 / API 0.3.15 与匹配 Server/活动 Bridge 2.3.8 实测共享封装 Via 0→1→0，两次保存 ACK 的源码长度为 28511/28241 字符；封装冷重开完整 DTO 保持创建状态并最终严格恢复原基线，引用 PCB Via 也为 0→1→0，其他读取部分保持基线。本轮按共享源持久编辑与诚实状态说明收口 #80，板级子过孔删除本身仍不保证持久。
- 本轮完整 `npm run build`（含保存回归、typecheck、API 文档/runtime 验证和打包）、`npm run lint` 及匹配 Server 全量 test/lint/多客户端验证通过。ACK 后身份失败、未 ACK、失联及恢复分支由本地回归验证；EDA v4 未实测。详见 [2.3.8 发布说明](../docs/releases/v2.3.8.md)。

- 写入前核对同库、同文档、同标签，并在最后身份读取后检查连接、活动角色与租约。封装未知提交使用同库同文档的完整 `footprint_read` 恢复；恢复可以使用新标签，但一次回读期间必须稳定。
- 新增完整读取、41 方法、身份变化、租约变化、长轮廓传输和恢复定向回归。正式 footprint_state 恢复、个人封装源码写回后重开的 5 控制图元完整 DTO 一致已通过；Via/Line/Polyline/String/独立 Arc 新案例创建、修改、删除通过。#80 持久 PCB 子过孔删除继续开放。

## [2.3.5] - 2026-10-05

- 名称属性查询的所有页固定使用关键词搜索，并在本地核对全部请求属性，返回 `searchImplementation:"keyword_name_filter"`；`mayHaveMore` 仍依据原生候选页，避免每页切换搜索后端。裸器件引用明确指定库时，同时核对返回记录的器件 UUID 与库 UUID，不一致则在创建前返回 `DEVICE_LOOKUP_MISMATCH`。
- 发布审查补修：普通 Pin 与 ComponentPin 按实际执行路径区分超时恢复；ComponentPin 仍要求所属器件全部引脚的完整回读。直线拆分/合并核验记录同网络、同层写前快照，要求本次新增或改变的有效线路，并返回 `changedPrimitiveIds`。过孔修改核对实际外径大于孔径，量化后的零环宽返回实际状态与差异。
- 普通 Pin 与 ComponentPin 共用原生 RPC 未确认分类；WebSocket is not open、transport closed、ECONNABORTED 等断连结果均返回 nativeCallSettled:false，并要求原宿主重启后完整回读。已结束但状态不匹配的调用仍区分为 nativeCallSettled:true。三种断连在两条实际处理路径、宿主重启策略与状态漂移分支均有针对性回归，已通过两轮本地复查。 同样统一图页导航与 PCB 直线/过孔创建的断连分类；回归包含原生状态已改变后才抛错的场景，继续要求宿主重启。
- 器件裸引用先经设备库解析为完整 DeviceItem，查无记录时不启动原生创建；保留完整记录、符号引用与单子件默认值的原生重载。
- ComponentPin 的 NC/引脚号修改通过当前页真实实例的异步 setter 提交，并核对引脚几何、其他属性及同器件引脚；失败恢复要求完整连接与语义快照，包含引脚 ID、位置、旋转、NC 状态并核对所属器件全部引脚，2.3.5 实机同一引脚 NC `true`→`false` 已验证，坐标及同器件其他引脚不变。
- 覆铜重建增加逐实例方法回退；批量与实例方法均缺失时返回明确的能力缺失诊断，不再误报需要打开 PCB。实机全板重建与 1 个边框/填充回读通过，能力分支另有本地回归。覆铜创建和修改增加闭合轮廓等价反向、起点及四位小数回读比较，实机等价反向与四位小数轮廓创建、修改已验证；原生重排已有覆铜优先级仍按实际 sideEffects 报告。
- 设备名称属性搜索核对返回名称，各页固定使用关键词搜索并核对全部请求属性；制造导出仅计算选定 domain/kind 的参数，BOM、文档、标准与仿真网表等分支使用自身格式和类型校验。
- 板框闭合轮廓与区域闭合轮廓支持等价方向、起点及已观察的四位小数坐标精度；板框开放路径只接受完整反向，保留真实轮廓差异和归一化诊断。区域多点轮廓写入须显式首尾闭合，补充 EDA 3.2.181 实机要求和闭合示例。实机板框反向、闭合区域反向及四位小数回读已通过。
- PCB 器件角度按模 360 度比较；部分元数据修改返回实际状态、失败分类和字段差异，继续要求受控回读。实机旋转 `-90`→`270` 及 `supplierId` / `otherProperty` 修改通过；创建将来源复制进工程库时，以原生返回来源与请求来源或同 ID 实际回读的一致性及真实几何确认，实机创建与工程库来源回读已验证。
- PCB 直线创建可核对原生拆分/合并的共线覆盖，实机返回 2 个实际 ID 并验证覆盖。过孔创建及尺寸修改只接受精确值或 EDA 3.2.181 实测的 0.2 mil 最近格点（`round_0_2_mil`），返回请求与实际尺寸；创建与修改已实测通过，真实尺寸偏差仍失败。
- 已知封装子过孔拒绝直接删除；其他过孔删除只承诺当前页内存消失，标明保存并重开后的持久性尚未验证。

- Bridge 结构化错误保留安全的诊断字段；绑定属性类型读取改用父图元属性与按 ID 查询，NetPort Name 的最终类型查询、单件和批量读取均返回 Attribute，并保留一致的真实父 ID、值和坐标。点导线转多线段在原生调用前拒绝，写后不匹配提供实际状态。
- 两轮本地全面审查、Bridge/Server 全量构建测试及 lint 通过；Bridge 构建包含全部新增回归脚本、TypeScript、API 文档、runtime 校验及打包，最新 DRC 与器件来源补修已再次通过完整构建。2.3.5 已安装并重启，无效引用预检、4 型号自动放置、NC 切换、名称过滤、Name 属性查询、原理图 CSV/网表/PDF 及 PCB BOM 导出通过；PCB 已测场景与最终复测项见 [23 项验证记录](https://github.com/hs150521/JLCEDA-MCP-Community/blob/v2.3.5/docs/issue-validation-2.3.5.md)。独立封装上下文、持久子过孔删除与旧原场景继续开放。

- PCB 区域原生创建和修改仅接收单轮廓多边形；多轮廓区域保持可读取。创建后完整回读确认未生效或属性不符时返回已知结果，不再误设未知提交隔离。
- 原理图器件几何修改增加匿名导线连通组核对：同组内移动不误报，脱线或跨组移动报告引脚连接变化；完整原理图读取支持较长超时预算。
- 原理图导线读取保留 EDA 中已有的零长度导线及其坐标，连接预检忽略其退化接触段，不再阻断整页的导线和 NetPort 操作；新写入的导线几何仍拒绝零长度线段。
- PCB 区域部分修改返回实际状态和未应用字段；删除改用完整区域列表验证，避免 EDA 删除后单件 API 的占位对象导致误报和不必要的写入隔离。
- `import_changes` 在当前 PCB 未归属板时提前返回明确原因和同板操作建议，避免 EDA 的前置对话框让原生 Promise 悬挂。
- 修复交互式器件放置检查仅依赖 `getAllPrimitiveId` 时漏报已提交器件：启动前同时记录当前页 `getAll` 对象基线，轮询中补读对象 ID，退出放置模式后合并两种来源核对结果。

- 修复自动布线即时观察的响应层级，MCP 实际返回中保留网络前后长度、图元数量及增删图元 ID，避免被 Bridge 深度限制截断。

## [1.0.0] - 2026-03-16

### 当前功能

**安装与激活**

- 扩展安装后随嘉立创 EDA 启动自动激活，无需手动触发。
- 在首页、原理图、PCB 顶部菜单栏注入「MCP Bridge」菜单，提供「连接设置」和「关于」入口。

**EDA 工具支持**

- 支持 API 检索、API 调用、当前上下文获取三个 AI 工具，AI 通过这三个工具操控嘉立创 EDA。
